# Privacy and data handling

The public application is a static replay. Its release contract permits bundled reviewed inputs and recorded outputs only. It does not offer live inference, browser key entry, message uploads, analytics, link previews, remote-image loading, or automatic outbound requests from message text.

The application does not independently verify senders, websites, or the absence of personal information. The SpaPhish source is described by its creators as manually anonymized. This project retains a fixed selected subset and does not claim that residual contact or personal information cannot remain. Do not submit real messages, credentials, account numbers, personal contact details, or private capture output to public issues.

Private capture is separate from the public build. The provider key exists only in the capture process. The recorder must not persist the key, authenticated headers, raw transport responses, environment dumps, private paths, or private capture logs in this repository or the Pages artifact.

GitHub Pages and other hosting infrastructure may process ordinary hosting requests. This project makes no claim that hosting infrastructure produces no logs.
